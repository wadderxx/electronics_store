 # 19\. Product + Category relationship

 `products/models.py`ga `category` qo‘shildi.

 Hozirgi Product modelining to‘liq holati:

```
from django.db import models

class Product(models.Model):
    category = models.ForeignKey(
        'categories.Category',
        on_delete=models.CASCADE,
        related_name='products',
        null=True,
        blank=True
    )
    name = models.CharField(max_length=200)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    description = models.TextField()
    stock = models.PositiveIntegerField(default=0)
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.name
```

 `null=True` va `blank=True` eski Product mavjud bo‘lgani uchun qo‘shildi.

2. Model nima?

Model — database'dagi ma'lumotlar tuzilishini Python klassi orqali belgilaydi.

Masalan, Product modeli electronics mahsulotlari haqidagi ma'lumotlarni ifodalaydi.

class Product(models.Model):
    name = models.CharField(max_length=200)
    price = models.DecimalField(max_digits=10, decimal_places=2)
    stock = models.PositiveIntegerField(default=0)


Bu misolda:

name — mahsulot nomi.
price — mahsulot narxi.
stock — ombordagi miqdor.

Eslatma: Bu o‘quv misoli. Loyihadagi haqiqiy model qo‘shimcha maydonlarga ega bo‘lishi mumkin.

3. Serializer nima?

Serializer — Django modelidagi ma'lumotlarni JSON ko‘rinishiga o‘tkazish va kelgan ma'lumotlarni tekshirish uchun ishlatiladi.

Bizning serializer:

class ProductSerializer(serializers.ModelSerializer):
    class Meta:
        model = Product
        fields = '__all__'

Kodning ma'nosi
ModelSerializer

Django REST Framework tomonidan berilgan tayyor serializer klassi.

Model maydonlari asosida ko‘p ishlarni avtomatik bajaradi.

class Meta

Serializer uchun sozlamalarni saqlaydi.

model = Product

Ushbu serializer qaysi model bilan ishlashini belgilaydi.

fields = '__all__'

Modelning serializer uchun mos barcha maydonlarini o‘z ichiga oladi.

Serializer qanday ishlaydi?

GET jarayoni:

Database → Product obyektlari → Serializer → JSON response

POST jarayoni:

Request JSON → Serializer → Validation → Database'ga saqlash → JSON response

PATCH jarayoni:

Request JSON → Serializer → O‘zgarishlarni tekshirish → Database'ni yangilash → JSON response

PATCH so‘rovida odatda partial=True orqali barcha maydonlarni qayta yuborish talab qilinmaydi.

4. ViewSet nima?

ViewSet — API endpointlari uchun tegishli amallarni bir joyda tashkil qilishga yordam beradi.

Har bir CRUD amali uchun alohida view yozish o‘rniga Django REST Framework'dagi ModelViewSet dan foydalanishimiz mumkin.

Bizning kod:

class ProductViewSet(viewsets.ModelViewSet):
    queryset = Product.objects.all()
    serializer_class = ProductSerializer
    permission_classes = [IsAdminOrReadOnly]


Bu yerda to‘rtta muhim tushuncha bor:

ModelViewSet — tayyor CRUD imkoniyatlari.
queryset — ishlanadigan obyektlar to‘plami.
serializer_class — ma'lumotlarni serializatsiya va validatsiya qiladigan klass.
permission_classes — request uchun ruxsatlarni tekshiradigan klasslar.
5. ModelViewSet CRUD metodlari
HTTP	Metod	Vazifasi
GET	list()	Barcha product'larni olish
GET	retrieve()	Bitta product'ni olish
POST	create()	Yangi product yaratish
PATCH	partial_update()	Qisman yangilash
PUT	update()	To‘liq yangilash
DELETE	destroy()	Product'ni o‘chirish
Endpoint misollari

Product ro‘yxati:

GET /api/products/products/


Bitta product:

GET /api/products/products/1/


Yangi product:

POST /api/products/products/


Product narxini o‘zgartirish:

PATCH /api/products/products/1/


Masalan, request body:

{
    "price": "1400.00"
}


Product'ni o‘chirish:

DELETE /api/products/products/1/


Bu URL'lar loyihamizda ishlatilayotgan endpointlar misolidir. Aniq URL'lar router va urls.py sozlamalariga bog‘liq.

6. Queryset nima?
queryset = Product.objects.all()


Bu qator ViewSet qaysi product obyektlari bilan ishlashini belgilaydi.

Product — model.
objects — model manager'i.
all() — barcha obyektlarni qamrab oluvchi QuerySet yaratadi.
queryset — ViewSet ishlatadigan atribut.

Masalan, database'da quyidagi product'lar bo‘lsa:

ID	Name	Price
1	Keyboard	150.00
2	Mouse	45.00
3	Monitor	300.00

Product.objects.all() ushbu obyektlarni qamrab oladi.

Muhim: Django QuerySet odatda lazy ishlaydi. Ya'ni SQL so‘rovi ko‘pincha ma'lumotlar kerak bo‘lgan vaqtda bajariladi.

Queryset faqat GET uchun emas. ModelViewSet ma'lum ID bo‘yicha obyektni topishda ham undan foydalanadi.

7. Serializer_class nima?
serializer_class = ProductSerializer


Bu qator ViewSet'ga qaysi serializer'dan foydalanishni aytadi.

GET paytida serializer obyektlarni JSON ko‘rinishiga o‘tkazadi.

POST va PATCH paytida esa kelgan ma'lumotlarni tekshirish va obyektni yaratish yoki yangilash jarayonida ishlatiladi.

Agar validatsiya muvaffaqiyatsiz bo‘lsa, odatda 400 Bad Request javobi qaytariladi.

8. Permission_classes nima?
permission_classes = [IsAdminOrReadOnly]


Bu yerda IsAdminOrReadOnly — loyihamizdagi custom permission klassi.

Uning maqsadi:

Oddiy foydalanuvchiga o‘qish amallariga ruxsat berish.
Staff foydalanuvchiga yozish amallarini ham bajarishga ruxsat berish.

Permission klassining soddalashtirilgan misoli:

from rest_framework.permissions import BasePermission, SAFE_METHODS

class IsAdminOrReadOnly(BasePermission):

    def has_permission(self, request, view):
        if request.method in SAFE_METHODS:
            return True

        return (
            request.user
            and request.user.is_authenticated
            and request.user.is_staff
        )


SAFE_METHODS quyidagilarni o‘z ichiga oladi:

GET
HEAD
OPTIONS

Ushbu misolda anonim foydalanuvchi ham o‘qish so‘rovlarini yuborishi mumkin. Bu authentication sozlamalariga ham mos bo‘lishi kerak.

is_staff=True — foydalanuvchi staff ekanini bildiradi. Bu is_superuser=True bilan bir xil emas.

Authorization — foydalanuvchiga qaysi amalni bajarish mumkinligini tekshirish.

Misol: oddiy user PATCH yuborganda 403 Forbidden olishi.

Bizda quyidagilar mavjud:

Register API
JWT login
Access token
Refresh token
Profile API

Hozirgi serializer kodi:

python
from rest_framework import serializers
from .models import Product


class ProductSerializer(serializers.ModelSerializer):
    class Meta:
        model = Product
        fields = '__all__'

    def validate_price(self, value):
        if value <= 0:
            raise serializers.ValidationError(
                "Price must be greater than zero."
            )
        return value

    def validate_stock(self, value):
        if value < 0:
            raise serializers.ValidationError(
                "Stock cannot be negative."
            )
        return value
Bizning biznes qoidamiz:

price > 0 bo‘lishi shart.

stock >= 0 bo‘lishi shart.

id avtomatik yaratiladi va read_only=True.

price majburiy.

stock modeldagi default=0 sababli ixtiyoriy.

validate_stock(-5) o‘zimiz yozgan validation xatosini qaytardi.

id.read_only → True.

price.required → True.

stock.required → False.

name.read_only → False.

name.write_only → False.

price yuborilmaganida 400 Bad Request qaytdi.

So‘rovda id=999 yuborilganda, yaratilgan product id=7 bilan qaytdi.

        return Response(CartSerializer(cart).data)

    def post(self, request):
        product_id = request.data.get('product')
        raw_quantity = request.data.get('quantity', 1)

        if product_id is None:
            return Response(
                {'error': 'Product ID is required.'},
                status=status.HTTP_400_BAD_REQUEST
            )

        # bool va kasrli sonlarni quantity sifatida qabul qilmaymiz.
        if (
            isinstance(raw_quantity, bool)
            or not str(raw_quantity).isdigit()
        ):
            return Response(
                {'error': 'Quantity must be a positive integer.'},
                status=status.HTTP_400_BAD_REQUEST
            )

        quantity = int(raw_quantity)

        if quantity < 1:
            return Response(
                {'error': 'Quantity must be at least 1.'},
                status=status.HTTP_400_BAD_REQUEST
            )

        with transaction.atomic():
            product = get_object_or_404(
                Product.objects.select_for_update(),
                pk=product_id
            )

            cart, _ = Cart.objects.get_or_create(user=request.user)

            item, created = CartItem.objects.get_or_create(
                cart=cart,
                product=product,
                defaults={'quantity': quantity}
            )

            new_quantity = quantity if created else item.quantity + quantity

            if new_quantity > product.stock:
                if created:
                    # Stock yetarli bo'lmasa, yangi item saqlanmasin.
                    item.delete()

                return Response(
                    {'error': 'Not enough product in stock.'},
                    status=status.HTTP_400_BAD_REQUEST
                )

            if not created:
                item.quantity = new_quantity
                item.save(update_fields=['quantity'])

        cart.refresh_from_db()
        return Response(
            CartSerializer(cart).data,
            status=status.HTTP_201_CREATED
        )


class CartItemView(APIView):
    permission_classes = [IsAuthenticated]

    def patch(self, request, item_id):
        raw_quantity = request.data.get('quantity')

        if (
            raw_quantity is None
            or isinstance(raw_quantity, bool)
            or not str(raw_quantity).isdigit()
        ):
            return Response(
                {'error': 'Quantity must be a positive integer.'},
                status=status.HTTP_400_BAD_REQUEST
            )

        quantity = int(raw_quantity)

        if quantity < 1:
            return Response(
                {'error': 'Quantity must be at least 1.'},
                status=status.HTTP_400_BAD_REQUEST
            )

        with transaction.atomic():
            item = get_object_or_404(
                CartItem.objects.select_for_update().select_related('cart'),
                pk=item_id,
                cart__user=request.user
            )

            product = get_object_or_404(
                Product.objects.select_for_update(),
                pk=item.product_id
            )

            if quantity > product.stock:
                return Response(
                    {'error': 'Not enough product in stock.'},
                    status=status.HTTP_400_BAD_REQUEST
                )

            item.quantity = quantity
            item.save(update_fields=['quantity'])
            cart = item.cart

        cart.refresh_from_db()
        return Response(CartSerializer(cart).data)

    def delete(self, request, item_id):
        cart = get_object_or_404(Cart, user=request.user)

        item = get_object_or_404(
            CartItem,
            pk=item_id,
            cart=cart
        )

        item.delete()
        cart.refresh_from_db()
        return Response(CartSerializer(cart).data)


class ClearCartView(APIView):
    permission_classes = [IsAuthenticated]

    def delete(self, request):
        cart, _ = Cart.objects.get_or_create(user=request.user)
        cart.items.all().delete()

        return Response(CartSerializer(cart).data)
